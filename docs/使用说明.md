# PeripheralBattery V0.1.0 使用说明

托盘显示无线外设电量的 Windows 小工具。绿色免安装，双击即用。

---

## 一、它是干什么的

在任务栏托盘里显示你的无线鼠标/键盘还剩多少电，鼠标移上去就能看到全部设备，点一下弹出面板。

**当前版本能读的设备**：雷柏（Rapoo）2.4G 接收器下的无线设备（VID `24AE`）。
**当前版本读不了的**：蓝牙耳机/键鼠、其它品牌的 2.4G 设备。原因见第六节。

---

## 二、怎么用

| 操作 | 结果 |
|---|---|
| 托盘图标 | 圆形进度环 + 中间数字。圆环走一圈代表满电，已走的弧长就是剩余电量；颜色：绿色 ≥50%、橙色 20–49%、红色 <20%、灰色表示没读到 |
| 左键单击 | 弹出面板：设备名、电量条、充电状态、DPI、信号强度；再点一下关闭 |
| 右键 | 菜单：显示面板 / 立即刷新 / 开机自启 / 设置 / 关于 / 退出 |

鼠标移上去只会看到 Windows 自带的简短提示，**不再弹小窗**（V0.1.0 已去掉悬停提示，避免和面板重复）。

**找不到图标？** Windows 11 默认会把新图标收进任务栏右边的 `^` 折叠区。点 `^` 找到 `21` 那个小方块，把它拖到任务栏上就固定住了。

数据大约每 3 秒自动刷新一次，不需要手动点刷新。

---

## 三、数据是从哪来的（重要）

程序**不向设备发送任何命令**，只接收设备自己周期性上报的状态帧（19 字节），按雷柏网页驱动里的字段布局解析：

| 字节位置 | 含义 |
|---|---|
| 第 9 字节 | 电量百分比（0–100） |
| 第 8 字节 | 充电状态（实测 1 = 未充电） |
| 第 4–7 字节 | X/Y DPI |
| 第 19 字节 | 连接标志 + 信号强度 |

**已用真机核对**：网页驱动 `hub.rapoo.cn` 显示 21% 时，程序读出的字节正是 21%，DPI 3700 也一致。

解析时还有一层强制校验：电量必须 ≤100、DPI 必须在 100–32000、配置槽必须 ≤15。任何一项不合常理，整帧丢弃、不显示数字——宁可空着也不显示错的。

「充电中」的判断目前**没有开启**：只确认了 `1 = 未充电`，其它取值的含义还没验证，所以只显示「未充电 / 充电状态未知」，不猜。

## 四、设置

右键 → 设置：

- **低电量阈值**：默认 20%，低于它就弹一次气泡提醒（同一电量只提醒一次）
- **休眠判定**：默认 90 秒。设备为省电会把上报间隔拉长（实测：使用中约 3 秒一次，空闲时约 45 秒一次），
  超过 90 秒没收到才标注「设备暂无上报」，数字变灰并显示最后读数时间
- **开机自启**：勾选后写入当前用户的启动项，开机只驻留托盘，不弹面板

设置保存在 `%LOCALAPPDATA%\PeripheralBattery\settings.json`，日志在同目录 `logs\` 下，保留 7 天。

## 五、常见问题

**1. 双击没反应 / 一闪而过**
程序是单实例的：如果已经在运行，再双击只会把面板唤出来。看托盘有没有图标。

**2. 提示"没有检测到可读取电量的外设"**
- 接收器插好了吗
- 鼠标底部的电源开关打开了吗
- 换一个 USB 口试试（避免 USB 3.0 干扰）
- 确认是雷柏的设备。其它品牌当前版本读不了

**3. 数字一直是同一个值**
正常。电量变化很慢，满电能用几百小时，可能几小时才掉 1%。设备休眠时会上报同一条状态。

**4. 显示"设备暂无上报"（数字变灰）**
鼠标进入休眠、关机或超出信号范围了，显示的是最后一次读数。动一下鼠标或按一下键就会立刻恢复。
这是正常现象，不是故障——无线设备为了省电会主动停止上报。

**5. SmartScreen 提示"Windows 已保护你的电脑"**
程序没有数字签名（个人工具，未购买证书）。点「更多信息」→「仍要运行」。
个别杀软会把单文件 exe 的自解压行为当成可疑，加信任即可。

**6. 点击面板后一闪就消失**
面板是"点外面就关"的弹出式窗口，属正常行为。点图标再开即可。

## 六、为什么有些设备读不到

Windows 没有统一的"外设电量"接口。2.4G 接收器的电量数据藏在各家自己的私有协议里：

| 设备类型 | 能否读 | 说明 |
|---|---|---|
| 雷柏 2.4G（本程序已适配） | ✅ | 解析设备主动上报的状态帧 |
| 罗技 LIGHTSPEED | ⬜ 未适配 | 走罗技自己的 HID++ 协议，可以后续加 |
| 蓝牙耳机/键鼠 | ❌ 本版不支持 | 需要走蓝牙标准电池服务，本版未实现 |
| 杂牌 2.4G 接收器 | ❌ 多数读不到 | 只转发按键和位移，根本不带电量数据 |

新增一个品牌 = 抓一次它自己的协议 + 写一个解析器，不是改个设置就能通吃。

---

## 七、怎么彻底删掉

1. 右键托盘图标 → 退出
2. 删除 `PeripheralBattery.exe`
3. 删除 `%LOCALAPPDATA%\PeripheralBattery` 整个目录（配置和日志）
4. 如果开过机自启：设置里取消勾选，或删除注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `PeripheralBattery`
